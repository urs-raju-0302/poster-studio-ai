# Final Testing Checklist

## Content and layout
- [ ] Built-in event-copy suggestions populate the fields correctly.
- [ ] Title, tagline, description, call-to-action, date, time, and venue can be edited.
- [ ] Each of the 10 templates renders without an exception.
- [ ] Each event category renders appropriately.
- [ ] All four canvas sizes can be selected and previewed.

## Design controls
- [ ] Quick palette updates the visible colors.
- [ ] Individual background and accent colors affect the poster.
- [ ] Font family and text sizes update the preview.
- [ ] Text alignment and vertical positioning work.
- [ ] Text effects remain readable against each background.
- [ ] Three design variations can be generated.

## Assets and export
- [ ] A logo can be uploaded and appears in the expected position.
- [ ] Optional QR content produces a scannable QR code when used.
- [ ] PNG export downloads and opens successfully.
- [ ] JPG export downloads and opens successfully.
- [ ] Exported dimensions match the selected poster format.
- [ ] Text is not clipped and important details have adequate contrast.

## Startup and privacy
- [ ] App starts with `python -m streamlit run app.py`.
- [ ] App works without an API key.
- [ ] `.venv`, secrets, and generated personal assets are excluded from Git.
- [ ] README and deployment instructions match the actual local-only behavior.
